# Obstacle Log — Mini Library Management System
**Project:** Mini Library Management System  
**Language:** Python  

### Issue Encountered  
Handling dates and implementing the logic required to standardize date formats for accurate comparison, particularly when identifying overdue books.

### Solution Implemented
The issue was resolved by learning and implementing Python's built-in datetime module. This helped me to represent dates in a standardized format and compare them easily for date-related operations.
